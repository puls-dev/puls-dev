# @puls-dev/firebase

Firebase Provider for Puls IaC. Provides Firebase Hosting, Functions, Firestore, Storage, Auth, Remote Config, and App Check builders. Includes local emulator-based testing helper hooks.

## Installation

```bash
npm install @puls-dev/core @puls-dev/firebase
```

For full documentation and Firebase setup, visit [pulsdev.io](https://pulsdev.io/).
