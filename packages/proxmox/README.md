# @puls-dev/proxmox

Proxmox VE Provider for Puls IaC. Provides VM cloning, template provisioning, cluster-aware node selection, and Ansible playbook integration.

## Installation

```bash
npm install @puls-dev/core @puls-dev/proxmox
```

For full documentation and Proxmox VE API configuration, visit [pulsdev.io](https://pulsdev.io/).
