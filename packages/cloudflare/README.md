# @puls-dev/cloudflare

Cloudflare Provider for Puls IaC. Provides DNS Zone, Workers, R2 Buckets, Pages, and KV Store builders.

## Installation

```bash
npm install @puls-dev/core @puls-dev/cloudflare
```

For full documentation and Cloudflare token configuration, visit [pulsdev.io](https://pulsdev.io/).
