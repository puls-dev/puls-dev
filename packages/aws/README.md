# @puls-dev/aws

AWS Cloud Provider for Puls IaC. Provides S3, Route53, CloudFront, Lambda, API Gateway, Fargate, RDS, SQS, SNS, IAM, and EC2 builders.

## Installation

```bash
npm install @puls-dev/core @puls-dev/aws
```

For full documentation and AWS credentials setup, visit [pulsdev.io](https://pulsdev.io/).
