# @puls-dev/gcp

Google Cloud Platform (GCP) Provider for Puls IaC. Provides Cloud Run, Cloud SQL, Secrets Manager, Pub/Sub, Cloud DNS, IAM, and Compute Engine VM builders.

## Installation

```bash
npm install @puls-dev/core @puls-dev/gcp
```

For full documentation and Google Cloud credentials setup, visit [pulsdev.io](https://pulsdev.io/).
